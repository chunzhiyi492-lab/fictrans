# FicTrans · 同人韩英译中

在同人阅读页就地把韩文 / 英文译成简体中文，保留原文，使用你自己的 DeepSeek API。

## 功能

- **就地翻译**：自动识别页面中可见的韩文 / 英文正文段落，在每段原文下方插入译文，不覆盖原文、不改动网站交互；页面滚动或动态加载新段落时自动继续识别。
- **翻译本页 / 停止**：一键翻译本页，停止后立即中止，正在请求的批次会被取消，不自动重试。
- **隐藏 / 显示译文**：一键收起或展开全部译文。
- **失败手动重试**：翻译失败的段落下方出现红色提示和「重试」按钮，由你手动决定是否重试，不会自动反复请求。
- **术语表**：逐行添加原词 → 固定译法（备注可选），适合作品名、角色名、CP 名、称呼、饭圈缩写；支持批量粘贴（`原词=译法`）与导出 / 导入 JSON 备份；只有当段落里真的出现这个词时，它才会随请求发给模型。
- **例句库**：逐行添加韩文 / 英文原句 → 你的中文译法，可勾选「置顶」；发送时按与当前段落的词汇重叠自动挑选最多 3 条作为风格参考，不会上传整份例句库。
- **本机缓存与用量统计**：译文缓存在本机 IndexedDB，重复段落命中缓存后不再重复计费；设置页底部按你填的单价估算累计花费。
- **首发适配**：geonat.kr（Born Halo 同人志），同时是通用的，对其他韩文 / 英文阅读站也能工作（自动识别正文区域）。

## 安装方法（Chrome / Edge，开发者模式加载已解压的扩展）

1. 打开 Chrome，地址栏输入 `chrome://extensions/` 回车。
2. 打开右上角「开发者模式 / Developer mode」。
3. 点「加载已解压的扩展程序 / Load unpacked」，选择本项目文件夹（就是包含 `manifest.json` 的那个目录）。
4. 工具栏出现 FicTrans 图标后，点它 →「打开设置」。

## DeepSeek Key 配置步骤

在设置页完成首次配置：

1. **接口与模型**
   - `Base URL` 默认 `https://api.deepseek.com`，一般不用改。
   - `模型` 默认 `deepseek-flash`（便宜、快）；追求译文质量可选 `deepseek-v4-pro`。
   - 粘贴你的 DeepSeek API Key（`sk-...`），点「保存 Key」。可点「测试连接」验证 Key 是否可用。
2. **费用与首次确认**
   - 单价默认填的是 `deepseek-flash` 谷时价（输入未命中 ¥1 / 命中 ¥0.02 / 输出 ¥4 每百万 token）。高峰时段（北京时间工作日 9–12、14–18）约为两倍；如果你选 v4-pro，请按 DeepSeek 官网改这三个数字。
   - 勾选「我已知晓……」，点「确认并保存」。未确认前扩展不会发送任何请求。
3. 完成后回到阅读页，点扩展图标 →「翻译本页」。

费用参考（deepseek-flash）：一章约 5,000–10,000 字韩文 ≈ 输入 3k–6k token + 输出 3k–6k token，谷时约 ¥0.03–0.10 / 章；重复段落命中缓存后更便宜。

## 权限说明

| 权限 | 用途 |
| --- | --- |
| `storage` | 在本机保存 Key、设置、术语表、例句库和用量统计。 |
| `unlimitedStorage` | 允许本机译文缓存（IndexedDB）不受常规容量限制，避免缓存被过早清理。 |
| `<all_urls>`（`host_permissions` 与内容脚本 `matches`） | 同人站不固定在一个域名：扩展需要在你亲手打开的任意韩文 / 英文阅读页上注入内容脚本、识别正文并插入译文，所以不能只写死某一个站点。它不会在后台主动打开或抓取任何页面，只处理你当前打开、且你点了「翻译本页」的页面。 |

## 隐私说明

- **Key 仅存本机**：DeepSeek API Key 只保存在本机 `chrome.storage.local`，设置页刷新后以 `sk-••••尾号` 掩码显示；扩展源码、日志、报错里都不会出现它（报错信息会先脱敏）。点「删除 Key」只删 Key。
- **文本只发送给你自己配置的接口**：只有被判定需要翻译的可见正文段落（韩文 / 英文）+ 命中的少数术语 + 最多 3 条相关例句，会发送到你填写的 API 地址（默认 `https://api.deepseek.com`）。不发送整页 HTML、隐藏内容、`<script>` / `<style>`、代码块、网址、邮箱、@用户名、输入框 / 表单、评论与私信、Cookie、任何个人信息。
- **不上传、不上报**：扩展不向除你填写的 API 地址外的任何服务器发数据，无统计、无上报。Key、设置、术语、例句在本机 `chrome.storage.local`；译文缓存在本机 IndexedDB。
- **删除**：「删除 Key」只删 Key；「清除翻译缓存」删本地译文缓存（下次重译重新计费）；「清除全部数据」一键清空 Key + 术语表 + 例句 + 缓存 + 用量统计。卸载前可在设置页先点「清除全部数据」。

## 已知限制

- geonat.kr 正文是 XE 模板（`.xe_content` 内 `p.MsoNormal` 段落），扩展已针对该结构优化；其他站点按「韩文密度最高的正文区」自动定位。
- 站点 robots.txt 禁止 AI 训练爬虫与 AI 代理抓取；本扩展不在后台抓取，只翻译你亲手点开的页面。
- 视频 / 插画页文字很少，翻译效果有限。
